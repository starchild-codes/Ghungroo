# Changelog

## 0.1.0 — initial release

- tokenizer, parser, AST, and evaluator for `.ghungroo` programs
- Teentaal, Jhaptaal, and Ektaal cycle definitions
- vilambit, madhya, and drut playback presets
- named Kathak phrase blocks
- tihai expansion
- `sam!` resolution assertions
- horizontal rhythm visualization
- Web Audio beat playback
- example compositions
- parser/evaluator tests and GitHub Actions CI
