# Contributing

Ghungroo is small on purpose.

If you want to contribute:

1. Keep changes narrow and explain the rhythmic semantics they introduce.
2. Add or update tests for parser/evaluator behavior.
3. Avoid presenting interface choices as universal or canonical Kathak practice.
4. Prefer permissive handling of user-entered bols over hard-coded claims about what is or is not “valid.”
5. Keep the project playful. A feature that requires a database is probably a different project.

Run the full check before opening a pull request:

```bash
npm install
npm run check
```
