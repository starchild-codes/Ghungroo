# Roadmap

Ghungroo v0.1 is intentionally tiny. Future ideas live here so they do not sneak into the first release.

## v0.2 candidates

- `dugun`, `tigun`, and `chaugun` subdivisions
- explicit rests and gaps inside tihai structures
- circular taal visualization
- syntax highlighting
- shareable programs encoded in the URL
- more taals
- custom taal declarations
- sampled percussion/ghungroo audio with clearly licensed recordings
- a “make this land on sam” puzzle mode

## Maybe someday

- a small REPL
- richer rhythmic AST transforms
- `.ghungroo` file import/export
- an editor extension

## Not planned

- user accounts
- a social feed
- an AI chatbot
- a database
- turning this into a research paper unless the joke gets completely out of hand
